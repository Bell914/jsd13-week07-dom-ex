# DOM JavaScript Exercises

Work through these in order. Each folder is self-contained — open its
`index.html` in a browser (and the console, F12) and edit its `script.js`.

1. **`01-selectors/`** — select elements (`querySelector`,
   `querySelectorAll`) and log/react to them.
2. **`02-content-and-classes/`** — read/write `textContent` and
   `innerHTML`, get/set attributes, toggle classes, use `dataset`.
3. **`03-events-basics/`** — `addEventListener` for click/mouseover/keydown,
   and the event object (`event.type`, `event.target`, `event.key`).
4. **`04-form-events/`** — form `submit` and `input` events,
   `preventDefault`, reading input values.
5. **`05-create-and-remove/`** — build elements with `createElement`,
   add them with `append`/`prepend`, remove them with `remove()`, all
   driven by the click events from step 3.
6. **`06-todo-list/`** — put it all together: a working to-do list
   (add, delete, mark done).

Stuck? Check out the `solution` branch (`git checkout solution`) to compare.
